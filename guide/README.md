# precis — a guided tour

precis pairs the MCP tool surface (what agents use) with a browser UI
(what you use): `precis web` serves a Drive-style front end over the
same store — papers, drafts, claims, figures, structures, todos, and
the background agent loop that works them.

The full tour — animated screen captures with narration, one section
per area of the UI — is being captured now and will appear here. Until
then, the written manual chapters (the same ones served at `/manual`
inside the app) cover the core workflows:

1. [Writing a paper](../src/precis_web/manual/01-writing-a-paper.md) —
   the smartdraft editor: chunk-native drafts, review passes, export to
   LaTeX/PDF/Word.
2. [Publishing claims](../src/precis_web/manual/02-publishing-claims.md) —
   claim hubs, evidence edges, and the nanopublication pipeline.
3. [Figures and permissions](../src/precis_web/manual/03-figures-and-permissions.md) —
   getting figures into a draft (upload or draw) and how they travel
   into every export.
4. [Watching the loop](../src/precis_web/manual/04-watching-the-loop.md) —
   quests: the background striving that reads, simulates, ranks, and
   reports while you're not looking.

Video: coming.
