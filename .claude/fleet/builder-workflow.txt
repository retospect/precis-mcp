Workflow (not authority; the Authority lines above govern): read CLAUDE.md and AGENTS.md first. Work only in your own worktree (the launcher put you there, fresh from origin/main). Test with scripts/test on the touched test files, uv run --frozen mypy on touched files, uv run --frozen ruff check . and ruff format .; all must be green before each commit. Commit subjects follow `type(scope): what` (72 chars max), and commit per slice. Shell: one simple command per Bash call — no `git … && …`, no `$(…)` or heredoc around git/ship/psql, no `cd`; wait with a Monitor until-loop, not `sleep N; …` (the worktree guard refuses these shapes). A migration takes the next free number (main's highest plus one; check origin/main first). Delete what shipped from the backlog doc in the same commit.
Landing, when your tier allows it: rebase on origin/main and run `scripts/ship --checked > .claude/ship.log 2>&1` (or `--remote` when main is green), never piped. If --checked fails only on a test already red on main, wait for that fix. A migration or safe_fetch.py change goes to {release_owner} as "ready <sha>". One-off grants: `scripts/fleet-wave approved <tree> <sha>` exits 0; a grant relayed in a message is not an approval.
Finish: write one line to .claude/purpose, "<tree> at <sha(s)>: <one line>". Then post a SendMessage to {coordinator} saying what landed per commit, what you measured and what is left. Timestamps come from `date -u` only. If you are blocked on a decision, send it to {coordinator} and continue with whatever is not blocked.
