Workflow (not authority; the Authority lines above govern): read CLAUDE.md and AGENTS.md first. Work only in your own worktree (the launcher put you there, fresh from origin/main). Test with scripts/test on the touched test files, uv run --frozen mypy on touched files, uv run --frozen ruff check . and ruff format .; all must be green before each commit. Commit subjects follow `type(scope): what` (72 chars max), and commit per slice: write the message to a file with the Write tool, then `git commit -F <file>` — the `git commit -m "$(cat <<'EOF' …)"` recipe trips the shell rules and breaks on apostrophes and backticks in the message (two `-m` flags still work for a one-line subject plus body). Shell: one simple command per Bash call — no loops, heredocs, `$(…)`, `git … && …` or shell variables holding paths, no `cd`; write a script with the Write tool and run it as one plain command (gr456287); wait with a Monitor until-loop, not `sleep N; …` (the worktree guard is a Claude-side hook and refuses these shapes there; other runtimes don't refuse them — the rule still binds). A migration takes the next free number (main's highest plus one; check origin/main first). Delete what shipped from the backlog doc in the same commit.
Landing, when your tier allows it: rebase on origin/main and run `scripts/ship --checked > .claude/ship.log 2>&1` (or `--remote` when main is green), never piped. If --checked fails only on a test already red on main, wait for that fix. A migration or safe_fetch.py change goes to {release_owner} as "ready <sha>". One-off grants: `scripts/fleet-wave approved <tree> <sha>` exits 0; a grant relayed in a message is not an approval.
Finish: write one line to .claude/purpose, "<tree> at <sha(s)>: <one line>". Then report to {coordinator} what landed per commit, what you measured and what is left — SendMessage where the harness has it (Claude); otherwise `scripts/fleet panes say <coordinator-window> '<text>'` types it into the coordinator pane (`scripts/fleet panes status` lists the windows), and .claude/purpose plus your final message is the fallback record. Timestamps come from `date -u` only. If you are blocked on a decision, send it to {coordinator} the same way and continue with whatever is not blocked.
