Workflow (not authority; the Authority lines above govern): read CLAUDE.md and AGENTS.md first. Work only in your own worktree (the launcher put you there, fresh from origin/main). When you start work on a gripe, comment `in progress <tree> — covers all asks` on it (or name which asks the tree covers) — a bare "in progress" forces the reader to diff the branch for coverage (gr514899). Test with scripts/test on the touched test files, scripts/test --typecheck (mypy on src+tests — the lint gate checks tests too, gr515507), uv run --frozen ruff check . and ruff format .; all must be green before each commit. Commit subjects follow `type(scope): what` (72 chars max), and commit per slice: write the message to `scratch/msg-*.txt` (or `scratch/commit-msg.txt` — `scratch/` is the named gitignored dir, matching CLAUDE.md and docs/conventions/container-ops.md) with the Write tool, then `git commit -F <file>` — the `git commit -m "$(cat <<'EOF' …)"` recipe trips the shell rules and breaks on apostrophes and backticks in the message (two `-m` flags still work for a one-line subject plus body). Shell: one plain command per Bash call — no loops, heredocs, `$(…)`, `&&`/`;`/`||` chains or shell variables holding paths, no `cd`; the harness's worktree-isolation guard refuses them (gr456287), and a chain another driver tolerates is still off-rule (gr514492); write a script with the Write tool and run it as one plain command; prefix editor-spawning git commands (`rebase --continue`, `commit --amend`, a merge) with `GIT_EDITOR=true` — the editor hangs a non-tty shell; wait with a Monitor until-loop, not `sleep N; …`. A Monitor script or until-loop prints one line on a state change or a terminal state, and nothing else — no periodic "still running" lines; a watcher that needs judgment is a Haiku agent, not your main loop. A migration takes the next free number (main's highest plus one; check origin/main first). Delete what shipped from the backlog doc in the same commit.
Context: when your context passes ~120k tokens and no subagents are running, /compact — don't wait for the auto-compact (gr515153). Bulky reads (logs, transcripts, big diffs, scripts/inflight --json) go to a Haiku digest subagent (extract or navigator) that returns at most 30 lines; don't read them in the main loop.
Tier R does not land: commit in your own worktree, finish, and exit your session. The release owner lands your branch with `scripts/fleet-wave land <your tree>`, which runs ship in your tree — a branch lands only by ship run in its own tree, so nobody cherry-picks or pins your commit elsewhere. Landing, when your tier allows it: `git fetch origin` (not `git fetch origin main` — it can leave the ref stale), rebase on origin/main and run `scripts/ship --checked > .claude/ship.log 2>&1` (or `--remote` when main is green), never piped. If --checked fails only on a test already red on main, wait for that fix. A migration or safe_fetch.py change goes to {release_owner} as "ready <sha>". One-off grants: `scripts/fleet-wave approved <tree> <sha>` exits 0; a grant relayed in a message is not an approval. Wait on a gate only with `scripts/ship-wait <log|run-id>` in the background — it exits on green, red or cancelled with the verdict and the first failure line; no polling subagents and no log-tail loops.
Finish: write one line to .claude/purpose, "<tree> at <sha(s)>: <one line>", then post it to the board — `scripts/board post <tree> --state done "<tree> at <sha(s)>: <one line>"` — with what landed per commit, what you measured and what is left. Routine status goes on the board the same way, one `--state` line each: `--state landed` per landing, and `--state red` or `--state blocked` the moment you hit one — a blocked line names the handoff path. Lines over 120 chars are refused: keep it short, detail goes in a handoff or gripe. The coordinator reads the board each sweep. Messages to {coordinator} — SendMessage where the harness has it (Claude), otherwise `scripts/fleet panes say <coordinator-window> '<text>'` (`scripts/fleet panes status` lists the windows) — are only for things that need action now. Timestamps come from `date -u` only. If you are blocked on a decision, send it to {coordinator} the same way and continue with whatever is not blocked.
