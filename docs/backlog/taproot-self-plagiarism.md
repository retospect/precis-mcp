# Taproot self-plagiarism — cross-draft hub reuse detection

A claim hub's canonical wording reused verbatim across two of our own
manuscripts risks self-plagiarism; not a first-paper problem. Directions (not
decided): an export-time "this claim already appears in draft X" warning;
vary phrasing on reuse (the hub stays the stable citation anchor, the
sentence needn't be verbatim); surface which own drafts cite each hub in the
claim-hub editor. Detection + guidance, not a correctness bug. Owner
`src/precis/taproot/` + export handlers. Needs design.
