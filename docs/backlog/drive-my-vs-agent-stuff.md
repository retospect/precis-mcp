# Drive: separate "my stuff" from "my agent's stuff"

Reto, 2026-10-16 (ruling 4 on `drive-filter-hierarchy.md`): "Accept agent
pollution for now", but separate "my stuff" from "my agent's stuff" lists
soon, because agents are far more active than Reto. Return history and
ownership lists today cannot tell a human's actions from an agent's working
under the same credentials (see the identity limitation in
`drive-filter-hierarchy.md`). Open question: a separate agent identity per
human, or an attribution column on the personal tables.
