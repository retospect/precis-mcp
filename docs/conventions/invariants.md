# Convention — the four invariants that cannot be undone

Four rules where a violation is irreversible or silently corrupts data. This
page is the only place they are stated in full; CLAUDE.md, AGENTS.md and the
agent definitions point here.

**Forward-only migrations.** Never edit a `src/precis/migrations/NNNN_*.sql`
that has shipped to `main`: the migration ledger stores a checksum per file,
so an edit mismatches on the next run against any DB that already applied it
and diverges prod from the file. A fix is a new numbered file. The baseline
snapshot `src/precis/migrations/baseline/schema.sql` is generated by
`scripts/bump` / `precis db dump-schema`, never hand-edited. Enforced by
`scripts/hooks/guard-sealed-migration.py` (PreToolUse; denies Edit/Write to a
migration present on `origin/main` or to `baseline/*`; escape hatch
`ALLOW_SEALED_MIGRATION_EDIT=1`), the checksum ledger in
`src/precis/store/migrate.py`, `tests/test_migrate.py`, and
`scripts/migration-check` (duplicate numbers across sibling branches).
Migrations and `safe_fetch.py` also take the full gate: `scripts/qgo-guard`
refuses them on the ungated deploy path (`tests/test_qgo_guard.py`).

**Body chunks are append-only.** A `chunks` row with `ord >= 0` and
`content_sha IS NULL` keeps its embeddings, summaries and keywords by row
identity, so an in-place `UPDATE` of `text` strands `chunk_embeddings` and
`chunk_summaries`. To change body text, DELETE the row and INSERT a new one
so the derived cascade re-runs. Exceptions: `ord < 0` card variants
(DELETE/re-INSERT by a registered synthesis pass, e.g. the chain-snapshot
pass in `precis.workers.chase`), and draft chunks (non-NULL `content_sha`),
which edit in place only through the draft-edit store ops, which log
`chunk_events`. Enforced in the database by the
`chunks_forbid_body_text_update` trigger (migration
`0068_chunks_forbid_body_text_update`); behaviour pinned by
`tests/test_chunk_append_only.py`.

**Agent-supplied URLs go through `safe_get` / `safe_stream`.** Any fetch whose
URL an agent, user or fetched document can influence uses
`utils/safe_fetch.py::safe_get` or `utils/safe_fetch.py::safe_stream`, which
re-validate every redirect hop against private/loopback/link-local ranges. A
raw `httpx` client with `follow_redirects=True` is an SSRF. Enforced by
review, the full gate for any `safe_fetch.py` change (`scripts/qgo-guard`),
and `tests/test_safe_fetch.py` / `tests/test_safe_fetch_fallback.py`. There
is no static ban on raw `httpx.Client` in new code; reviewers check for it.

**`uv` for everything.** Dependencies resolve from `uv.lock`; bare `pip`,
`pytest`, `mypy` or a host `python` use an unpinned environment and report
phantom failures (the torch-free host lacks `marker`, `sympy`, ...). Tests
run through `scripts/test` (dev container, test DB wired; `--impacted`
narrows, `--typecheck` runs mypy over `src tests`); other tools through `uv
run`. Not hard-blocked by a hook: the convention is carried by `scripts/test`
being the only wired path and by the gate, which runs the same container
commands.
