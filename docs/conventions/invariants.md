# Convention — the four invariants that cannot be undone

Four rules where a violation is irreversible or silently corrupts data. This
page is the only place they are stated in full; CLAUDE.md, AGENTS.md and the
agent definitions point here.

**Forward-only migrations.** Never edit a `src/precis/migrations/NNNN_*.sql`
that has shipped to `main`: the migration ledger stores a checksum per file,
so an edit mismatches on the next run against any DB that already applied it
and diverges prod from the file. A fix is a new numbered file. The baseline
snapshot `src/precis/migrations/baseline/schema.sql` is generated by
`scripts/bump` / `precis db dump-schema`, never hand-edited. Enforced by
`scripts/hooks/guard-sealed-migration.py` (PreToolUse; denies Edit/Write to a
migration present on `origin/main` or to `baseline/*`; escape hatch
`ALLOW_SEALED_MIGRATION_EDIT=1`), the checksum ledger in
`src/precis/store/migrate.py`, `tests/test_migrate.py`, and
`scripts/migration-check` (duplicate numbers across sibling branches,
worktrees and `origin/main`; `--taken` lists claimed numbers and the next
free one — mint off that, not just this tree's directory listing).
Migrations and `safe_fetch.py` also take the full gate: `scripts/qgo-guard`
refuses them on the ungated deploy path (`tests/test_qgo_guard.py`).
A migration that runs `DROP INDEX` must cite more than `pg_stat` `idx_scan`
in its header: (1) the foreign keys whose referential-integrity probes use the
index (a parent DELETE/UPDATE probes the child's FK column), and (2)
`EXPLAIN` plans of every periodic job that touches the table (retention
sweepers, GC passes), run against production-sized data. A zero `idx_scan`
only covers the stats window; jobs that run rarely do not show up in it.
Evidence: 0200 (`1d28d286c`) dropped the `llm_call_log` hash-column b-tree
indexes on `idx_scan = 0`; every retention sweep then hit `statement_timeout`
(mainly the `route_log.gc()` anti-join, which only a plan check would have
caught) until 0208 (`e1845852a`) recreated the indexes and the `gc()` rewrite.

**Body chunks are append-only.** A `chunks` row with `ord >= 0` and
`content_sha IS NULL` keeps its embeddings, summaries and keywords by row
identity, so an in-place `UPDATE` of `text` strands `chunk_embeddings` and
`chunk_summaries`. To change body text, DELETE the row and INSERT a new one
so the derived cascade re-runs. Exceptions: `ord < 0` card variants
(DELETE/re-INSERT by a registered synthesis pass, e.g. the chain-snapshot
pass in `precis.workers.chase`), and draft chunks (non-NULL `content_sha`),
which edit in place only through the draft-edit store ops, which log
`chunk_events`. Enforced in the database by the
`chunks_forbid_body_text_update` trigger (migration
`0068_chunks_forbid_body_text_update`); behaviour pinned by
`tests/test_chunk_append_only.py`.

**Agent-supplied URLs go through `safe_get` / `safe_stream`.** Any fetch whose
URL an agent, user or fetched document can influence uses
`utils/safe_fetch.py::safe_get` or `utils/safe_fetch.py::safe_stream`, which
re-validate every redirect hop against private/loopback/link-local ranges. A
raw `httpx` client with `follow_redirects=True` is an SSRF. Enforced by
review, the full gate for any `safe_fetch.py` change (`scripts/qgo-guard`),
and `tests/test_safe_fetch.py` / `tests/test_safe_fetch_fallback.py`. There
is no static ban on raw `httpx.Client` in new code; reviewers check for it.

**No paper/journal chunk text in the repo** (Reto 2026-10-23). Fixtures carry
ids, hashes, numbers and short labels — never verbatim paper or journal
text: the `chunks` table's text is upstream-copyrighted material, and a push
to this public repo is forever (a later delete does not unpublish it). A
test that needs the *shape* of paper text builds it at runtime. Enforced by
`tests/test_paper_text_gate.py`: a prose scan over `tests/fixtures/` and
`tests/data/` pinned against the shrink-only baseline
`tests/data/paper_text_baseline.json`; a deliberate exception carries
`paper-text-gate: allow — <reason>` or, where the format allows no comments,
an entry in `tests/data/paper_text_allowlist.json` (one reason per entry).

## SQL and layering gotchas

- **Double `%` in psycopg SQL.** A literal `%` in a parameterised query is a
  placeholder (`ProgrammingError: only '%s','%b','%t' are allowed`): write
  `LIKE 'ask-user:%%'` or pass the pattern as a param. Web-route tests use a
  `FakeStore` that never hands SQL to psycopg, so this passes green and 500s
  in prod; raw SQL needs a real-Postgres test
  (`docs/conventions/testing.md` §Raw SQL).
- **`ADD CONSTRAINT IF NOT EXISTS` is not Postgres.** `ADD COLUMN IF NOT
  EXISTS` exists; `ADD CONSTRAINT` has no `IF NOT EXISTS` form — the file
  fails at apply time, on prod. To redefine a constraint: `ALTER TABLE t
  DROP CONSTRAINT IF EXISTS c;` then `ALTER TABLE t ADD CONSTRAINT c ...`
  (migrations 0201, 0224). Pinned by `tests/test_migration_sql_idioms.py`.
- **Workers never import handlers.** A worker that needs another kind's
  behaviour calls `Hub.sibling('<kind>')` (e.g. `Hub.sibling('conv')`), not
  `from precis.handlers…`.

## Outbound calls are polite

Every outbound HTTP call to a third party goes through the politeness core in
`utils/http.py`: `with_backoff` / `call_with_backoff` (one limiter token per
attempt, full jitter, `Retry-After` parks the limiter row, 401/403 fatal, a
breaker per service) with an entry in `POLICIES` and `polite_user_agent()`.
The wrappers `polite_send` (supply vendors), `polite_fetch` (chem resolvers),
`paced_requests` (library `requests` sessions) and `external_retry` count too.
`safe_get` / `safe_stream` only guard SSRF; the call around them still has to
be polite. A new host with no limiter row auto-seeds `host:<netloc>`; add a
named row (migration) when the provider publishes a rate. Never spoof a
browser User-Agent.

Enforced by `tests/test_outbound_polite_ratchet.py`: an AST walk over `src/`
that fails on any httpx/requests/urllib/aiohttp call, or `http_client()`, whose
enclosing function does not use the core. Its `_ALLOWLIST` holds only
cluster-internal or operator-configured endpoints (embedder, llm serving,
capability probe, readyz, ASKCOS, deadman, health digest, key probes), each
with a one-line reason. Fix the call site; do not widen the allowlist.

One admission policy: every outbound call resolves an `EffectivePolicy`
(`utils/outbound_policy.py` — the module docstring owns the model: classes,
the parked_until gate, the `llm-api` hold, the merge). Per field, later
non-NULL wins: class default → `POLICIES[service]` → the row's override
columns → the caller's deadline. The DB columns are the only layer an
operator can change without a deploy: write them with
`precis limits set <row> ...` (audited, `--dry-run` previews the resolved
policy), never hand SQL; `get(kind='job', id='/limits')` shows each field
and the layer that set it.

Every wait carries a bound: `tests/test_outbound_timeout_ratchet.py` is an
AST walk over `src/`+`scripts/` that pins unbounded waits — `subprocess`
and `Popen` waits without `timeout=`, `psycopg.connect` without
`connect_timeout`, `Thread.join`/`Queue.get`/`Lock.acquire`/
`Future.result`/`as_completed`, blocking `fcntl.flock`, `asyncio`/`anyio`
waits and `*ClientSession` awaits outside `wait_for`/`timeout`, and bare
`httpx.<method>`/`urlopen` — to `tests/data/outbound_timeout_baseline.json`,
a one-way floor keyed `file::function::callee` (never line numbers, so
unrelated edits don't churn it). A new key or a risen count fails: bound
the call. A fallen count fails too — lower the floor with
`uv run python tests/test_outbound_timeout_ratchet.py --write` (it refuses
to raise or add an entry). `while True` polls and `tests/` are report-only.
Ruff `S113` (requests without `timeout=`) is on for `src/`+`scripts/`;
`tests/`/`deploy/`/`docker/` sit under per-file-ignores as report-only.

**`uv` for everything.** Dependencies resolve from `uv.lock`; bare `pip`,
`pytest`, `mypy` or a host `python` use an unpinned environment and report
phantom failures (the torch-free host lacks `marker`, `sympy`, ...). Tests
run through `scripts/test` (dev container, test DB wired; `--impacted`
narrows, `--typecheck` runs mypy over `src tests`); other tools through `uv
run`. Hard-blocked in Bash by `scripts/hooks/guard-bare-python-tools.py` (bare
`pytest`/`pip`/`mypy`, `python -m pytest|pip`; `uv run`, `uvx`, `scripts/test`
and `ssh` remotes pass; any parse doubt allows), and the gate runs the same
container commands.
