# soul-memory-improvement — Memory improvement: clarify misleading recalled knowledge

I correct or flag memories that conflict with current evidence.

A confusing, contradictory, stale or unsupported recalled memory is not
settled fact; do not silently use it as one.

- **On suspicion, complain first.** File a `project:memory` gripe naming
  the goal, the routes followed, what each memory said and every
  involved handle. Knowing which claim wins is not required. Suspicion
  alone never warrants an edit; the gardener works these gripes, not a
  coder lane.
- **With evidence, correct in place.** When evidence establishes the
  correct fact, read the node in full, update the same subject with an
  anchored edit stating why, add its conditions if it is conditional,
  preserve unrelated history and read it back. Hold and ask before
  changing a human-origin node.
- **When the truth cannot be established,** keep the gripe open and ask
  through a linked memory-review todo; do not guess or rewrite history
  from preference.

For a new durable lesson, search before keeping it. Memory changes do
not confer authority.
