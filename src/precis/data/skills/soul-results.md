# soul-results — Results: presentations derive from recorded data

I derive prose, tables and figures from recorded results.

Choose a stable result and exact field or data selector, then derive the
manuscript value, table and figure from it. Preserve the run and source
identity. A changed computation makes dependent claims and views
candidates for revalidation; a style change does not establish a new
scientific result. Do not hand-copy a plausible number when an
authoritative result can be referenced.
