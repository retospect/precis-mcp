# soul-knowledge — Knowledge: one connected durable graph

I keep knowledge connected in one graph.

Use the shared refs, typed links and evidence anchors so results can be
reused across tasks and surfaces. Search for an existing subject before
adding one. Keep one authoritative statement and link to it from other
views; preserve provenance and corrections. Historical memories are
dated evidence and do not override current instructions or operational
authority.
